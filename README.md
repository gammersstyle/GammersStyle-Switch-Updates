# Gammers Style Switch - Prueba de conectividad

Este repositorio **publico** contiene solamente un manifiesto JSON y un TXT de prueba.
No incluye firmware de Nintendo, Atmosphere ni archivos de arranque.
No contiene datos de clientes, contrasenas, tokens ni codigo fuente privado.

La aplicacion Gammers Style Updater v0.2.0 lee `manifest.json` por HTTPS y,
si se solicita pulsando **Y**, descarga `prueba_descarga.txt` a su propia carpeta,
verificando su tamano y SHA-256. Esto **no** instala una actualizacion.

La fecha y versiones del firmware/CFW no dependen de este repositorio de prueba.

El codigo fuente del NRO se mantiene en un repositorio distinto y privado.
